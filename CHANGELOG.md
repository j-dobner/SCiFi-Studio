# Changelog

## v22.0 public preview — 2026-11-27

- First clean public distribution of the SCiFi editor, based on the v21 workspace and vector tools.
- 34 embryogenesis and 23 Carnegie stage illustrations, with original editable geometry retained.
- Blank starting canvas, one developmental workflow template, editable paths, shapes, text, synthetic plots, icon editing, local projects and SVG/PNG export.
- Original private artwork collections and templates requiring rights review omitted, including manufacturer-specific artwork.
- MIT software license, CC0 developmental artwork and separate interface-glyph notices.
- Automated geometry, JavaScript syntax and Chromium smoke tests passed before publication. This is a preview, not a fully validated stable release.
