# SCiFi Studio

**Stem Cell integrated Figure illustrator**

An offline-first scientific vector figure editor for stem cell research, developmental biology, molecular biology and laboratory workflows.

**Project creator, scientific direction and lead development:** Jochen Dobner (human-directed, AI-assisted development), IUF - Leibniz-Institut für umweltmedizinische Forschung GmbH.

## Release status

SCiFi Studio is preparing its first public software release. The editor is not yet available for download from this repository. The intended library includes the complete human embryogenesis and Carnegie stage collections.
